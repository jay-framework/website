## Brand & Style
The visual identity of this design system is rooted in the concept of **Cybernetic Minimalism** mixed with **Glassmorphism**. It is designed to feel high-tech, precise, and authoritative, catering to developers who demand performance and security. 

The aesthetic draws inspiration from deep-space command centers: high-contrast elements against an infinite dark void. We utilize semi-transparent surfaces (Glassmorphism) to represent the "layers" of the AI stack, while sharp "Circuitry" accents provide a sense of structure and data flow. The emotional response should be one of absolute control, technical sophistication, and architectural stability.

## Colors
The palette is dominated by **Midnight Navy** and **Deep Space Black**, providing a low-light foundation that reduces eye strain during long coding sessions.

- **Primary (Cyber Blue):** Used for primary actions and active states. It represents the "core" power of the AI.
- **Secondary (Circuitry Cyan):** Used for data visualization, accents, and secondary highlights. It mimics the glow of fiber optics.
- **Tertiary (Ruby Red):** Reserved strictly for critical warnings, errors, and the "Zero Trust" boundary violations. It is a high-attention color derived from the spider's eyes.
- **Neutral:** A range of desaturated blues and greys used for text and structural borders to maintain a cohesive technical atmosphere.

## Typography
The typography system uses a dual-approach to balance human readability with technical precision.

- **Sora** is the display face, chosen for its geometric, modern construction that feels engineered and futuristic.
- **Inter** handles the heavy lifting for body copy, ensuring maximum legibility across all browser environments.
- **JetBrains Mono** is utilized for metadata, labels, and code snippets. This "Monospace Accent" reinforces the developer-first nature of the product.

All headlines should use tight tracking to maintain a "dense" and professional appearance.

## Layout & Spacing
This design system utilizes a **12-column fluid grid** for desktop and a **4-column grid** for mobile. The layout is structured around a strict 8px baseline rhythm to ensure mathematical consistency—reflecting the "Strict Boundaries" of the framework.

- **Desktop:** 64px side margins with 24px gutters.
- **Tablet:** 32px side margins with 16px gutters.
- **Mobile:** 16px side margins with 12px gutters.

Large sections are separated by significant vertical whitespace to prevent information density from becoming overwhelming, while data-heavy components (like dashboards or code editors) use a "compact" density setting.

## Elevation & Depth
Depth is created through **Tonal Layering** and **Backdrop Blurs** rather than traditional drop shadows.

- **Level 0 (Base):** The deep #04070F background.
- **Level 1 (Surfaces):** Semi-transparent glass (#0A0F1E at 70% opacity) with a 12px backdrop blur.
- **Level 2 (Active/Hover):** Surfaces receive a subtle 1px inner stroke of Cyber Blue (#00D2FF) at 20% opacity, creating a "glowing edge" effect.
- **Level 3 (Modals):** High-contrast borders with a light cyan outer glow (4px blur, 10% opacity) to signify priority.

## Shapes
The shape language is "Soft-Technical." We avoid fully organic roundness to maintain a sense of structural integrity. 

- **Standard Elements:** 4px radius (Soft) for buttons, inputs, and tags.
- **Containers:** 8px to 12px radius for cards and modals.
- **Accents:** Use 45-degree chamfered corners on decorative elements or "Status" indicators to mimic hardware circuitry.

## Components

### Buttons
Primary buttons use a solid Cyber Blue fill with high-contrast navy text. Secondary buttons are "Ghost" style with a 1px Cyan border that glows on hover. All buttons use the Sora font for a bold, actionable feel.

### Input Fields
Inputs are dark-filled glass containers with a bottom-only border by default. Upon focus, the border transitions to a full Cyan glow, and a subtle monospace label appears above the field.

### Chips & Tags
Used for status and categories. They should look like "modules" with monospace text. "Zero Trust" verified tags use the Ruby Red accent for high visibility.

### Copy Tooltip (clipboard-copy feedback)
When using `<jay:clipboard-copy>`, add a "Copied!" tooltip that appears above the button on click. Use the shared `.copy-tooltip-anchor` and `.copy-tooltip` utility classes from `theme.css`.

**Pattern (icon-only button):**
```html
<jay:clipboard-copy text="...">
  <button ref="copyBtn" class="my-copy-btn copy-tooltip-anchor">
    <span if="!copied"><!-- copy icon --></span>
    <span if="copied"><!-- check icon --></span>
    <span if="copied" class="copy-tooltip" role="status" aria-live="polite">Copied!</span>
  </button>
</jay:clipboard-copy>
```

**Pattern (button with label):**
```html
<jay:clipboard-copy text="...">
  <button ref="copyBtn" class="my-btn copy-tooltip-anchor">
    <span>npm create jay@latest</span>
    <span if="!copied" class="copy-icon"><!-- copy icon --></span>
    <span if="copied" class="copy-icon"><!-- check icon --></span>
    <span if="copied" class="copy-tooltip" role="status" aria-live="polite">Copied!</span>
  </button>
</jay:clipboard-copy>
```

Key rules:
- The button must have `copy-tooltip-anchor` (sets `position: relative`).
- The tooltip uses `copy-tooltip` class (styled in `theme.css` with the `tooltip` typography token).
- Move `aria-live="polite"` to the tooltip span (not the icon span) so screen readers announce "Copied!" text.
- The button should have `overflow: visible` if it clips child content (e.g. small icon buttons).
- The tooltip uses the `micro` animation preset (150ms, ease-in-out) and respects `prefers-reduced-motion`.

### Cards
Cards are the primary structural unit. They must feature a subtle grid-pattern background (low opacity) and a 1px border. The header of the card should be separated by a hairline stroke.

### Data Visualization
Charts and graphs must use the secondary Cyan and primary Blue exclusively. Error states in data must be represented by the Ruby Red to immediately alert the user of boundary breaches.
